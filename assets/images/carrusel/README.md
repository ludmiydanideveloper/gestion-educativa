# Carrusel del login

Fotos de la escuela / alumnos estudiando que se muestran en carrusel en la
pantalla de inicio de sesión (panel izquierdo en pantallas anchas, header en
mobile).

Para agregar una foto, subí el archivo a esta carpeta con alguno de estos
nombres (se detectan automáticamente, sin tocar código):

```
carrusel_1.jpg
carrusel_2.jpg
carrusel_3.jpg
carrusel_4.jpg
carrusel_5.jpg
carrusel_6.jpg
```

También se aceptan las extensiones `.jpeg`, `.png` y `.webp`. Se pueden usar
menos de 6 fotos (con 1 sola alcanza, no rota); si no hay ninguna, se muestra
un degradé institucional de respaldo en vez de fallar.

Recomendado: fotos horizontales, buena luz, mínimo ~1200px de ancho.
